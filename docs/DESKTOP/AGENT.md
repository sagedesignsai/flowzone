# Desktop Agent Guide\n\nThe Desktop Agent is an AI-powered agent that operates a full Linux GUI environment using computer-use tools and autonomous coding capabilities.\n\n## Agent Capabilities\n\nThe agent can:\n- **See** the desktop via screenshots\n- **Control** mouse and keyboard\n- **Launch** applications (Chrome, VS Code, terminal, etc.)\n- **Run** shell commands and scripts\n- **Code** autonomously via OpenCode CLI\n- **Verify** actions by taking screenshots\n\n## System Instructions\n\nThe agent follows these core principles:\n\n```\n1. ALWAYS start by taking a screenshot to see current state\n2. Use runOpenCodeTask for complex coding, scaffolding, refactoring\n3. Use runShellCommand for system operations: packages, servers, logs\n4. Use launchApp to open applications: browsers, terminals, editors\n5. After every significant action, take a screenshot to verify\n6. Use keyboard and mouse tools to interact with GUI applications\n```\n\n## Workflow Examples\n\n### Example 1: Build a React App\n\n**User:** \"Create a React todo app with add/delete functionality\"\n\n**Agent Flow:**\n```\n1. takeScreenshot() → See desktop\n2. launchApp(\"xterm\") → Open terminal\n3. takeScreenshot() → Verify terminal opened\n4. runShellCommand(\"cd /home/user && npx create-react-app todo-app\") → Scaffold\n5. takeScreenshot() → Verify creation\n6. runOpenCodeTask(\"Create a todo component with add/delete in src/App.js\") → Code\n7. runShellCommand(\"cd /home/user/todo-app && npm start\", background: true) → Start dev server\n8. takeScreenshot() → Verify server started\n9. launchApp(\"google-chrome\", \"http://localhost:3000\") → Open in browser\n10. takeScreenshot() → Show final result\n```\n\n### Example 2: Debug a Node.js App\n\n**User:** \"Fix the failing tests in my project\"\n\n**Agent Flow:**\n```\n1. takeScreenshot() → See desktop\n2. launchApp(\"code\", \"/home/user/project\") → Open VS Code\n3. takeScreenshot() → Verify VS Code opened\n4. runShellCommand(\"cd /home/user/project && npm test\") → Run tests\n5. takeScreenshot() → See test output\n6. runOpenCodeTask(\"Fix the failing tests in __tests__/app.test.js\") → Debug\n7. runShellCommand(\"cd /home/user/project && npm test\") → Verify fix\n8. takeScreenshot() → Show passing tests\n```\n\n### Example 3: Deploy to GitHub\n\n**User:** \"Push my changes to GitHub\"\n\n**Agent Flow:**\n```\n1. takeScreenshot() → See desktop\n2. launchApp(\"xterm\") → Open terminal\n3. runShellCommand(\"cd /home/user/project && git status\") → Check status\n4. runShellCommand(\"cd /home/user/project && git add .\") → Stage changes\n5. runShellCommand(\"cd /home/user/project && git commit -m 'Update feature'\") → Commit\n6. runShellCommand(\"cd /home/user/project && git push\") → Push\n7. takeScreenshot() → Verify push succeeded\n```\n\n## OpenCode Integration\n\nOpenCode is an autonomous coding agent that runs inside the sandbox. Use it for:\n\n**Multi-file changes:**\n```typescript\nawait runOpenCodeTask({\n  prompt: \"Add TypeScript types to all functions in src/utils.ts and src/helpers.ts\"\n})\n```\n\n**Complex refactoring:**\n```typescript\nawait runOpenCodeTask({\n  prompt: \"Refactor the authentication module to use JWT tokens instead of sessions. Update all related files.\"\n})\n```\n\n**Scaffolding:**\n```typescript\nawait runOpenCodeTask({\n  prompt: \"Create a new Next.js API route at /api/users that fetches users from the database and returns JSON\"\n})\n```\n\n**Debugging:**\n```typescript\nawait runOpenCodeTask({\n  prompt: \"Debug the failing test in __tests__/auth.test.js. The test expects a 200 response but gets 401.\"\n})\n```\n\n## Development Workflow\n\n### Starting a Dev Server\n\n```typescript\n// 1. Install dependencies\nawait runShellCommand({ \n  command: \"npm install\",\n  workdir: \"/home/user/project\"\n})\n\n// 2. Start server in background\nawait runShellCommand({ \n  command: \"npm run dev\",\n  background: true,\n  workdir: \"/home/user/project\"\n})\n\n// 3. Verify it started\nawait takeScreenshot()\n\n// 4. Open in browser\nawait launchApp(\"google-chrome\", \"http://localhost:3000\")\n\n// 5. Show result\nawait takeScreenshot()\n```\n\n### Checking Logs\n\n```typescript\n// View application logs\nawait runShellCommand({ \n  command: \"tail -f /home/user/project/logs/app.log\"\n})\n\n// Check system logs\nawait runShellCommand({ \n  command: \"journalctl -n 50\"\n})\n\n// Check port usage\nawait runShellCommand({ \n  command: \"lsof -i :3000\"\n})\n```\n\n### Installing Packages\n\n```typescript\n// npm\nawait runShellCommand({ \n  command: \"npm install express\",\n  workdir: \"/home/user/project\"\n})\n\n// pnpm (preferred in this sandbox)\nawait runShellCommand({ \n  command: \"pnpm add express\",\n  workdir: \"/home/user/project\"\n})\n\n// yarn\nawait runShellCommand({ \n  command: \"yarn add express\",\n  workdir: \"/home/user/project\"\n})\n```\n\n## Visual Verification\n\nAlways take screenshots to verify actions:\n\n```typescript\n// ❌ Don't assume\nawait mouseLeftClick({ x: 640, y: 400 })\nawait keyboardType({ text: \"hello\" })\n\n// ✅ Verify each step\nawait takeScreenshot()  // See current state\nawait mouseLeftClick({ x: 640, y: 400 })\nawait takeScreenshot()  // Verify click worked\nawait keyboardType({ text: \"hello\" })\nawait takeScreenshot()  // Verify text was typed\n```\n\n## Error Recovery\n\nIf something goes wrong:\n\n```typescript\n// 1. Take screenshot to see error\nawait takeScreenshot()\n\n// 2. Check logs\nawait runShellCommand({ command: \"cat /var/log/app.log\" })\n\n// 3. Investigate\nawait runShellCommand({ command: \"npm test\" })\n\n// 4. Fix with OpenCode\nawait runOpenCodeTask({ prompt: \"Fix the error in src/app.js\" })\n\n// 5. Verify fix\nawait takeScreenshot()\n```\n\n## Best Practices\n\n### ✅ Do\n- Take screenshots liberally — they're your eyes\n- Use OpenCode for complex coding tasks\n- Use background mode for long-running processes\n- Verify each significant action\n- Check for errors before proceeding\n- Use workdir parameter to ensure correct context\n\n### ❌ Don't\n- Assume actions succeeded without verification\n- Try to code manually with keyboard (use OpenCode)\n- Ignore error messages\n- Leave processes running without checking they started\n- Use blocking mode for dev servers (use background: true)\n- Forget to install dependencies before running code\n\n## Common Tasks\n\n### Clone a Repository\n```typescript\nawait runShellCommand({ \n  command: \"git clone https://github.com/user/repo.git\",\n  workdir: \"/home/user\"\n})\n```\n\n### Create a New Project\n```typescript\nawait runOpenCodeTask({\n  prompt: \"Create a new Next.js project with TypeScript and Tailwind CSS\",\n  workdir: \"/home/user\"\n})\n```\n\n### Run Tests\n```typescript\nawait runShellCommand({ \n  command: \"npm test\",\n  workdir: \"/home/user/project\"\n})\n```\n\n### Build for Production\n```typescript\nawait runShellCommand({ \n  command: \"npm run build\",\n  workdir: \"/home/user/project\"\n})\n```\n\n### Deploy\n```typescript\nawait runShellCommand({ \n  command: \"npm run deploy\",\n  workdir: \"/home/user/project\"\n})\n```\n\n## Limitations\n\n- **Single display:** 1280×800 resolution\n- **No GPU:** CPU-only rendering\n- **No audio:** Screenshots only\n- **Timeout:** Default 5 minutes (extended during agent run)\n- **No persistence:** Sandbox is ephemeral\n- **No multi-monitor:** Single screen only\n\n## Troubleshooting\n\n### Sandbox Timeout\n**Problem:** Agent stops mid-task  \n**Solution:** Timeout is extended during agent execution. If still timing out, break task into smaller steps.\n\n### Port Already in Use\n**Problem:** Dev server won't start  \n**Solution:** Check with `lsof -i :PORT` and kill existing process\n\n### Package Installation Fails\n**Problem:** npm/pnpm install errors  \n**Solution:** Clear cache with `npm cache clean --force` or `pnpm store prune`\n\n### Application Won't Launch\n**Problem:** launchApp returns success but app doesn't appear  \n**Solution:** Take screenshot to verify, check logs, try alternative app\n\n### Screenshot Shows Old State\n**Problem:** Screenshot doesn't reflect recent action  \n**Solution:** Wait a moment and take another screenshot, or check if action actually executed\n"
