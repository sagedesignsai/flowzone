# Desktop API Reference\n\nComplete API documentation for desktop sandbox management and agent communication.\n\n## Endpoints\n\n### POST /api/desktop\n\nCreate a new desktop sandbox and start VNC stream.\n\n**Request:**\n```json\n{\n  \"chatId\": \"chat-123\",\n  \"projectId\": \"project-456\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"sandboxId\": \"sbx_abc123def456\",\n  \"vncUrl\": \"https://e2b.dev/vnc?token=xyz789\"\n}\n```\n\n**Response (401):**\n```json\n{\n  \"error\": \"Unauthorized\"\n}\n```\n\n**Response (500):**\n```json\n{\n  \"error\": \"E2B_API_KEY is not configured\"\n}\n```\n\n**Environment Variables:**\n- `E2B_API_KEY` (required) — E2B API key\n- `E2B_DESKTOP_TIMEOUT_MS` (optional) — Sandbox timeout in milliseconds (default: 300000 = 5 min)\n- `NEXT_PUBLIC_URL` (optional) — Flowzone API URL for sandbox environment\n- `GITHUB_TOKEN` (optional) — GitHub token for git operations\n- `GIT_AUTHOR_NAME` (optional) — Git author name\n- `GIT_AUTHOR_EMAIL` (optional) — Git author email\n- `ANTHROPIC_API_KEY` (optional) — Anthropic API key\n- `OPENAI_API_KEY` (optional) — OpenAI API key\n\n**Metadata Stored:**\n```json\n{\n  \"userId\": \"user-123\",\n  \"projectId\": \"project-456\",\n  \"chatId\": \"chat-123\"\n}\n```\n\n**Notes:**\n- Sandbox is created with template `flowzone-desktop`\n- Resolution: 1280×800 @ 96 DPI\n- VNC URL is temporary and sandbox-specific\n- Sandbox auto-terminates after timeout\n\n---\n\n### DELETE /api/desktop\n\nKill an existing desktop sandbox.\n\n**Request:**\n```json\n{\n  \"sandboxId\": \"sbx_abc123def456\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true\n}\n```\n\n**Response (400):**\n```json\n{\n  \"error\": \"sandboxId is required\"\n}\n```\n\n**Response (401):**\n```json\n{\n  \"error\": \"Unauthorized\"\n}\n```\n\n**Response (500):**\n```json\n{\n  \"error\": \"Sandbox not found or already terminated\"\n}\n```\n\n**Notes:**\n- Terminates sandbox immediately\n- Cleans up VNC stream\n- Idempotent (safe to call multiple times)\n\n---\n\n### POST /api/chat/[id]/desktop\n\nStream chat completion using the Desktop Agent.\n\n**Request:**\n```json\n{\n  \"messages\": [\n    {\n      \"id\": \"msg-1\",\n      \"role\": \"user\",\n      \"content\": \"Take a screenshot and tell me what you see\",\n      \"parts\": [\n        {\n          \"type\": \"text\",\n          \"text\": \"Take a screenshot and tell me what you see\"\n        }\n      ]\n    }\n  ],\n  \"sandboxId\": \"sbx_abc123def456\"\n}\n```\n\n**Response (200 - SSE Stream):**\n```\nevent: message\ndata: {\"type\":\"message\",\"id\":\"msg-2\",\"role\":\"assistant\",\"parts\":[{\"type\":\"text\",\"text\":\"I'll take a screenshot...\"}]}\n\nevent: tool-call\ndata: {\"type\":\"tool-call\",\"toolName\":\"takeScreenshot\",\"toolCallId\":\"call-1\",\"args\":{}}\n\nevent: tool-result\ndata: {\"type\":\"tool-result\",\"toolCallId\":\"call-1\",\"result\":{\"screenshot\":\"iVBORw0KGgo...\",\"width\":1280,\"height\":800}}\n\nevent: message\ndata: {\"type\":\"message\",\"id\":\"msg-2\",\"role\":\"assistant\",\"parts\":[{\"type\":\"text\",\"text\":\"I can see the desktop with...\"}]}\n```\n\n**Response (400):**\n```json\n{\n  \"error\": \"sandboxId is required to use the desktop agent\"\n}\n```\n\n**Response (401):**\n```json\n{\n  \"error\": \"Unauthorized\"\n}\n```\n\n**Response (500):**\n```json\n{\n  \"error\": \"E2B_API_KEY is not configured\"\n}\n```\n\n**Parameters:**\n- `id` (path) — Chat ID\n- `messages` (body) — Array of UIMessage objects\n- `sandboxId` (body) — Sandbox ID from POST /api/desktop\n\n**Message Format:**\n```typescript\ninterface UIMessage {\n  id: string\n  role: \"user\" | \"assistant\"\n  content: string\n  parts: UIMessagePart[]\n}\n\ntype UIMessagePart = \n  | { type: \"text\"; text: string }\n  | { type: \"image\"; image: string; mimeType?: string }\n  | { type: \"file\"; data: string; mimeType: string }\n  | { type: \"tool-call\"; toolName: string; toolCallId: string; args: Record<string, unknown> }\n  | { type: \"tool-result\"; toolCallId: string; result: unknown }\n```\n\n**Notes:**\n- Streaming response via Server-Sent Events (SSE)\n- Sandbox timeout extended during agent execution\n- Previous messages loaded from database\n- Chat history saved on completion\n- Agent runs with DesktopSandboxContext for tool access\n\n---\n\n## Client Usage\n\n### Creating a Desktop Session\n\n```typescript\n// 1. Create sandbox\nconst response = await fetch(\"/api/desktop\", {\n  method: \"POST\",\n  headers: { \"Content-Type\": \"application/json\" },\n  body: JSON.stringify({ chatId: \"chat-123\", projectId: \"proj-456\" })\n})\n\nconst { sandboxId, vncUrl } = await response.json()\n\n// 2. Store in state\nsetDesktopSandbox(sandboxId, vncUrl)\n\n// 3. Render VNC iframe\n<iframe src={vncUrl} />\n```\n\n### Sending Messages to Desktop Agent\n\n```typescript\n// 1. Prepare messages\nconst messages = [\n  {\n    id: \"msg-1\",\n    role: \"user\",\n    content: \"Create a React app\",\n    parts: [{ type: \"text\", text: \"Create a React app\" }]\n  }\n]\n\n// 2. Send to desktop endpoint\nconst response = await fetch(`/api/chat/${chatId}/desktop`, {\n  method: \"POST\",\n  headers: { \"Content-Type\": \"application/json\" },\n  body: JSON.stringify({ messages, sandboxId })\n})\n\n// 3. Handle SSE stream\nconst reader = response.body.getReader()\nconst decoder = new TextDecoder()\n\nwhile (true) {\n  const { done, value } = await reader.read()\n  if (done) break\n  \n  const text = decoder.decode(value)\n  const lines = text.split(\"\\n\")\n  \n  for (const line of lines) {\n    if (line.startsWith(\"data: \")) {\n      const data = JSON.parse(line.slice(6))\n      // Handle message, tool-call, tool-result events\n    }\n  }\n}\n```\n\n### Stopping a Desktop Session\n\n```typescript\n// 1. Delete sandbox\nawait fetch(\"/api/desktop\", {\n  method: \"DELETE\",\n  headers: { \"Content-Type\": \"application/json\" },\n  body: JSON.stringify({ sandboxId })\n})\n\n// 2. Clear state\nclearDesktopSandbox()\n```\n\n---\n\n## Error Handling\n\n### Common Errors\n\n| Error | Cause | Solution |\n|-------|-------|----------|\n| `E2B_API_KEY is not configured` | Missing environment variable | Set `E2B_API_KEY` in `.env` |\n| `Unauthorized` | Not authenticated | Login first |\n| `sandboxId is required` | Missing sandboxId in request | Create sandbox first with POST /api/desktop |\n| `Sandbox not found` | Sandbox expired or doesn't exist | Create new sandbox |\n| `No AI provider configured` | Missing AI model | Set `AI_GATEWAY_API_KEY` or model provider key |\n\n### Retry Logic\n\n```typescript\nasync function createDesktopWithRetry(maxRetries = 3) {\n  for (let i = 0; i < maxRetries; i++) {\n    try {\n      const response = await fetch(\"/api/desktop\", {\n        method: \"POST\",\n        body: JSON.stringify({ chatId, projectId })\n      })\n      \n      if (response.ok) {\n        return await response.json()\n      }\n      \n      if (response.status === 500) {\n        // Retry on server error\n        await new Promise(r => setTimeout(r, 1000 * (i + 1)))\n        continue\n      }\n      \n      throw new Error(await response.text())\n    } catch (error) {\n      if (i === maxRetries - 1) throw error\n    }\n  }\n}\n```\n\n---\n\n## Rate Limiting\n\n- **Sandbox creation:** 1 per user per chat (enforced by design)\n- **Message streaming:** No limit (depends on model provider)\n- **Tool execution:** No limit (depends on sandbox resources)\n\n---\n\n## Timeouts\n\n- **Sandbox creation:** 60 seconds\n- **Agent execution:** 800 seconds (13 minutes)\n- **Sandbox idle:** 300 seconds (5 minutes, configurable)\n- **VNC stream:** Persistent until sandbox terminates\n\n---\n\n## Security\n\n- **Authentication:** Required for all endpoints\n- **Authorization:** Users can only access their own sandboxes\n- **Isolation:** Each sandbox is isolated per user\n- **API Key:** Server-side only (never exposed to client)\n- **VNC URL:** Temporary and sandbox-specific\n- **Tool Access:** All commands validated through tool definitions\n\n---\n\n## Monitoring\n\n### Logs\n\nCheck server logs for:\n- Sandbox creation/deletion events\n- Agent execution traces\n- Tool call results\n- Error messages\n\n### Metrics\n\nTrack:\n- Sandbox creation success rate\n- Average sandbox lifetime\n- Tool execution times\n- Agent completion times\n- Error rates by type\n"
