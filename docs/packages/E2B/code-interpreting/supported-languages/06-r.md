# R

## Overview

Run R code inside the sandbox for statistical analysis and data visualization.

## Basic Usage

```typescript
import { Sandbox } from '@e2b/code-interpreter';

const sbx = await Sandbox.create();
const execution = await sbx.runCode('print("Hello, world!")', { language: 'r' });
console.log(execution);
```

## Features

- Full R support
- ggplot2 for visualization
- dplyr for data manipulation
- Statistical analysis libraries
- Package management via CRAN

## Data Analysis

```typescript
const code = `
data <- c(1, 2, 3, 4, 5)
mean(data)
sd(data)
`;

await sbx.runCode(code, { language: 'r' });
```

## Data Manipulation

```typescript
const code = `
library(dplyr)
df <- data.frame(x = 1:5, y = 6:10)
df %>% filter(x > 2) %>% select(y)
`;

await sbx.runCode(code, { language: 'r' });
```

## Visualization

```typescript
const code = `
library(ggplot2)
df <- data.frame(x = 1:10, y = 1:10)
ggplot(df, aes(x = x, y = y)) + geom_point()
`;

await sbx.runCode(code, { language: 'r' });
```

## Install Packages

```typescript
const code = `
install.packages('ggplot2')
library(ggplot2)
`;

await sbx.runCode(code, { language: 'r' });
```

## Best Practices

1. Use vectorized operations
2. Install packages before use
3. Handle data frames efficiently
4. Use ggplot2 for visualization
5. Stream output for monitoring
